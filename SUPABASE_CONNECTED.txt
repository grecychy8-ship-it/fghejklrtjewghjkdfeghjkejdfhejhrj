Q: Which server do I use?
A: Use the NEW ONE: server-supabase.js
   Old one (server.js) uses SQLite and is outdated

Q: How do I start the server?
A: node server-supabase.js

Q: What port is it on?
A: Port 5000 (same as before)
   http://localhost:5000

Q: Do I need to change the frontend?
A: No! Frontend stays the same
   Only backend database changed

Q: How do I verify it's working?
A: Test the login endpoint:
   curl -X POST http://localhost:5000/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"student@demo.com","password":"Password123!"}'

Q: What if I get an error?
A: Check SUPABASE_SETUP_GUIDE.md troubleshooting section
   Or check if SQL schema was executed
   Or verify .env file has correct credentials

Q: How do I add data?
A: Use Supabase Dashboard Table Editor or:
   POST /api/auth/register to create users
   POST /api/projects to create projects

Q: Can I still use SQLite?
A: Yes, keep using server.js if you want
   But supabase-db.js is better for production
